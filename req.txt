# 📊 Portfolio OS — Requirement Specification Document

---

## 1. 📌 Overview

**Portfolio OS** is a local-first portfolio intelligence system that enables users to:

* Build, analyze, and manage investment portfolios
* Simulate long-term performance
* Assess risk (market, geopolitical, inflation)
* Visualize allocation and insights
* Store portfolios securely on their local machine

The system is designed to be:

* 🔐 Privacy-first (no cloud dependency)
* 🧠 Insight-driven (not just tracking)
* ⚡ Fast and extensible

---

## 2. 🎯 Objectives

* Provide actionable portfolio insights
* Enable both manual and automated portfolio creation
* Simulate long-term outcomes (5Y, 10Y)
* Incorporate real-world risks (inflation, geopolitical events)
* Deliver a clean fintech-grade UI experience

---

## 4. 🧩 Core Features

---

### 4.1 Portfolio Input (Manual Mode)

**User can:**

* Add stocks/assets manually
* Assign:

  * Name
  * Value
  * Category (core, growth, defensive, global, hedge, cash)

---

### 4.2 Portfolio Analysis Engine

**System computes:**

* Total portfolio value
* Allocation (%) across categories
* Rebalancing suggestions
* Health score (0–10)

---

### 4.3 Portfolio Wizard (Auto Build Mode)

**Inputs:**

* Investment amount
* Risk level (low / medium / high)

**Output:**

* Suggested allocation
* Category-wise investment distribution

---

### 4.4 Projection Engine

**Calculates:**

* 5-year projection
* 10-year projection

**Assumption:**

* CAGR-based growth (default ~12%)

---

### 4.5 Risk Engine

Simulates portfolio under stress scenarios:

| Scenario  | Impact |
| --------- | ------ |
| Mild      | -10%   |
| Recession | -20%   |
| Crash     | -30%   |

---

### 4.6 Portfolio Health Score

Score based on diversification:

* Global exposure
* Hedge allocation
* Defensive assets
* Core stability
* Cash buffer

---

### 4.7 Data Persistence (Local)

* SQLite database
* Stored on user machine
* No cloud dependency

---

### 4.8 Save Portfolio Feature

Users can:

* Save portfolio names
* View saved portfolios

---

## 6. 🏗️ System Architecture

---

### 6.1 Monorepo Structure

```
portfolio-os/
├── backend/ (FastAPI)
├── frontend/ (React + Vite)
└── SQLite DB
```

---

### 6.2 Backend

* Language: Python
* Framework: FastAPI
* ORM: SQLAlchemy
* DB: SQLite

**Modules:**

* Models
* Schemas
* Services (analysis, projections, risk, builder)
* API routes

---

### 6.3 Frontend

* Framework: React (Vite)
* State: useState
* API: Axios
* Charts: Recharts

---

## 7. 🔐 Security & Data Safety

---

### 7.1 Local-First Design

* No external API dependency

---

### 7.2 Input Validation

* Pydantic schemas

---

### 7.3 Environment Config

* `.env` for sensitive configs

---

### 7.4 CORS Protection

* Restricted to local frontend

### 7.5 Database Safety
